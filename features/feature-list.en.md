# ✅ **Feature List (with short descriptions)**

### 🧭 **Passthrough MR Room**

See the real world + XR panels anchored in space.

### 📂 **XR Spatial Panels**

Movable/rotatable 3D panels: Notes, PDFs, To-Do, Images, Snapshots, Sticky Notes, Pomodoro, Mind Map, Calendar…

### 🧑‍🤝‍🧑 **Real-Time Collaboration**

Instant Firestore sync: panels, transforms, text, participants.

### 🔊 **Voice Groups (Agora)**

All users hear the global group (groupId = 0).

### 🔇 **Focus Bubbles**

Instant private chat: isolated audio + ghost visual effect.

### 🏰 **Private 3D Bubble Spaces**

A real instant 3D private room for selected users only:

* separate environment
* private panels
* isolated audio
* isolated Firestore data

### 🧊 **Avatars / Orbs**

Colored XR sphere for each user + states (online, typing, ghost).

### 🗄️ **Web Console**

Upload PDFs/Images → instantly spawned as XR panels.

### 💾 **Firestore Serverless Backend**

100% Firebase: participants, panels, sync, presence.

### 🎤 **Agora Multi-channel Voice**

Audio groups based on `voiceGroupId`.

---

# 👤 **User Capabilities**

A connected user can:

* See the MR passthrough room
* Move / resize / rotate panels
* Create panels (Notes, PDFs, To-Do, etc.)
* Edit content in real time
* See other participants & their status
* Speak with everyone (global group)
* Select 1+ users → enter a Focus Bubble
* Enter a Private 3D Bubble Room
* Return to global group
* Read/view files uploaded through the web console
* Stay automatically synced with everyone
