# ✅ **Lista de Funcionalidades (com breve descrição)**

### 🧭 **Sala MR com Passthrough**

Ver o mundo real + painéis XR ancorados no espaço.

### 📂 **Painéis XR Espaciais**

Painéis 3D movíveis/rotativos: Notas, PDFs, To-Do, Imagens, Capturas, Sticky Notes, Pomodoro, Mind Map, Calendário…

### 🧑‍🤝‍🧑 **Colaboração em Tempo Real**

Sincronização instantânea Firestore: painéis, transformações, texto, participantes.

### 🔊 **Voice Groups (Agora)**

Todos os utilizadores ouvem o grupo global (groupId = 0).

### 🔇 **Focus Bubbles**

Chat privado instantâneo: áudio isolado + efeito visual de ghost.

### 🏰 **Private 3D Bubble Spaces**

Uma verdadeira sala 3D privada instantânea apenas para utilizadores selecionados:

* ambiente separado
* painéis privados
* áudio isolado
* Firestore isolado

### 🧊 **Avatares / Orbes**

Esfera XR colorida por utilizador + estado (online, typing, ghost).

### 🗄️ **Consola Web**

Upload de PDFs/Imagens → aparecem instantaneamente como painéis XR.

### 💾 **Backend Serverless Firestore**

100% Firebase: participantes, painéis, sync, presença.

### 🎤 **Agora Multi-channel Voice**

Grupos de áudio baseados no `voiceGroupId`.

---

# 👤 **Possibilidades de um Utilizador**

Um utilizador ligado pode:

* Ver a sala MR com passthrough
* Mover / redimensionar / rodar painéis
* Criar painéis (Notas, PDFs, To-Do, etc.)
* Editar conteúdos em tempo real
* Ver outros participantes e o estado deles
* Falar com todos (grupo global)
* Selecionar 1+ pessoas → entrar numa Focus Bubble
* Entrar numa Private 3D Bubble Room
* Voltar ao grupo global
* Ler/ver ficheiros enviados através da consola web
* Estar sempre sincronizado automaticamente
